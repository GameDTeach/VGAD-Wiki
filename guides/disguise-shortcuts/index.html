Disguise Keyboard Shortcuts

The shortcuts worth learning first for d3 Manager and the Designer timeline.

This is a reference sheet, not a walkthrough — keep it open on a second screen while you work.

d3 Manager

The launcher you see first, for opening and organising projects.

What it does Keys
New project Ctrl + N
Open the projects folder Ctrl + P
Expand or collapse projects Space
Exit Alt + F4

Designer timeline

Where you'll spend most of a session. Section breaks divide the timeline into named chunks you can jump between.

What it does Keys
Zoom the timeline Alt + Scroll
Add a section break Alt + S
Remove a section break Alt + M
One more worth knowing

Adding a RenderStream video layer to the timeline is Ctrl + L. It comes up in the Disguise ICVFX Workflow guide, so it's here for completeness.

The full list
