Project files not associated with the launcher

You get this error come up every time you open the Epic Launcher and go to the Unreal Engine tab.

uproject files are not associated with this launcher

Why it happens

This usually happens after the Unreal Engine installation has been moved, or a folder it sits in has been renamed. Your .uproject files lose their link to the Epic Games Launcher, so Windows no longer knows what to open them with.

What the fix actually does

A small program called the Unreal Version Selector is what opens a .uproject file and hands it to the right version of Unreal. Running it once with -fileassociations on the end tells it to register itself with Windows again, so double-clicking a project works the way it used to.

Your projects themselves are fine. Nothing inside them is changed.

The fix

You'll make a shortcut to the Unreal Version Selector, add -fileassociations to it, and run it once as administrator.

Find the Unreal Version Selector

  1. Open File Explorer and go to the Epic Games Launcher's binaries folder. By default that is:

    C:\Program Files (x86)\Epic Games\Launcher\Engine\Binaries\Win64

    If it isn't there, try C:\Program Files\Epic Games\Launcher\Engine\Binaries\Win64.

  2. Look for UnrealVersionSelector.exe in that folder.

Make a shortcut to it

  1. Right-click UnrealVersionSelector.exe and choose Create shortcut.
  2. Right-click the new shortcut and choose Properties.
  3. In the Target field, click at the very end of the text and add a space followed by -fileassociations. It should end up looking like this:

    "C:\...\UnrealVersionSelector.exe" -fileassociations

  4. Click Apply, then OK.
Outside the quotation marks

The path in the Target field is wrapped in quotation marks. -fileassociations goes after the closing quotation mark, not inside it. Put it inside and Windows reads it as part of the file name and can't find the program.

Run it

  1. Right-click the shortcut you just changed and choose Run as administrator.
  2. Wait a few seconds while Windows updates its file associations. There may be nothing to see while it happens.
Check it worked

Open the Epic Games Launcher and click on the Unreal tab. It should open without the error now.
